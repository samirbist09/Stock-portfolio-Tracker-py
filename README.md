# Stock Portfolio Tracker – CodeAlpha Internship

## Description
This project is a simple Stock Portfolio Tracker built using Python. It calculates the total investment value based on user input and predefined stock prices.

## Features
- Hardcoded stock prices
- User input for stock selection and quantity
- Calculates total investment
- Saves portfolio data to a text file

## Technologies Used
- Python
- File Handling

## How to Run
1. Ensure Python is installed
2. Run the program using:
   python stock_tracker.py
